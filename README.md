# Mam Birthday Surprise ❤️

Upload every file in this folder to the same GitHub repository level. Do not put photos or audio in a separate folder.

- `index.html` — website
- `photo1.jpg` — birthday reveal / Mam portrait
- `photo2.jpg`–`photo11.jpg` — couple memories
- `photo12.jpg`–`photo15.jpg` — four family photos, shown first in the memory sequence in the order provided
- `Bol_Do_Na_Zara.m4a` — starts at 15 seconds after successful login
- `Oboseshe.m4a` — starts automatically when the first song ends
- `love_moments.mp4` — short animated romantic moment

The memory sequence shows the four family photos first, with a family-togetherness message, then the couple memories. The last-before-final slide creates a photo heart collage with Mam’s birthday portrait in the centre.

GitHub Pages is public, and the login is a front-end surprise gate rather than secure authentication.
